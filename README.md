# Oratio

Computer engineering capstone by Adam Dia, Yadah Ngolo, Fayza Oyarekhua, Mohamed Boustta and Omon Okondo. Oratio is an off-grid, mesh-based emergency telecommunications system.

The system comprises of wearable nodes participating in a wireless mesh, a raspberry pi hosting a UDP server for forwarding and a dashboard.

## Organization

- `fw` contains all of our firmware
- `hw` contains PCB schematics and enclosure Adam
- `sw` contains the UDP server and dashboard
